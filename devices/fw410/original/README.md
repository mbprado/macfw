# Original vendor material

This directory is reserved for immutable copies of original M-Audio FireWire 410 driver material used for reverse engineering.

## Current reference

```text
M-AudioFireWireBeBoB.kext
```

The working copy supplied for this project is currently kept outside the repository while its provenance, licensing and repository size implications are evaluated.

Do not modify original vendor artifacts in place. Analysis outputs belong under `../analysis/`.

## Recommended metadata

For each original artifact, record:

- filename
- source
- acquisition date
- version
- SHA-256 hash
- architecture
- macOS version where it was observed working
- hardware/firmware revision, when known

Example:

```text
Artifact: M-AudioFireWireBeBoB.kext
Version: 1.10.6 "Sierra mod"
Architecture: x86_64
Bundle ID: com.m-audio.driver.firewire
```
