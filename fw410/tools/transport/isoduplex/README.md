# isoduplex

Guarded FW410 duplex-isoc transport experiment.

The tool deliberately starts with the safest possible transmit test:

- reserve the corrected 48 kHz blocking-mode maximum payloads
- establish both CMP directions
- start a local Mac -> FW410 isochronous transmitter
- transmit AM824 NODATA packets only
- simultaneously receive FW410 -> Mac packets
- report whether capture remains NODATA or becomes sample-bearing
- restore the exact original PCR values and release ISO resources

This stage does **not** transmit PCM samples yet.  It exists to verify that the
FW410 sees actual packets in both directions before we add data-bearing packets
with strict DBC/SYT timing.

At 48 kHz the corrected blocking-mode maximum packet sizes are:

- capture: 8 + (8 events * 5 positions * 4 bytes) = 168 bytes
- playback: 8 + (8 events * 11 positions * 4 bytes) = 360 bytes

The 8-byte term is the CIP header, which is part of the FireWire isochronous
payload (the outer IEEE-1394 isochronous header is generated by IOFireWireLib).

Build:

```sh
make
```

Dry-run:

```sh
./isoduplex
```

Execute:

```sh
./isoduplex --execute
```

Raw capture dump:

```sh
./isoduplex --execute --raw
```
